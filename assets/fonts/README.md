# Font Montserrat

Thêm các file font Montserrat vào thư mục này (tải từ [Google Fonts - Montserrat](https://fonts.google.com/specimen/Montserrat)):

- `Montserrat-Regular.ttf`
- `Montserrat-Medium.ttf`
- `Montserrat-SemiBold.ttf`
- `Montserrat-Bold.ttf`
- `Montserrat-Italic.ttf`

Sau đó chạy:

```bash
npx react-native-asset
```

Rồi build lại app (iOS: `pod install` trong thư mục `ios`, sau đó build).
